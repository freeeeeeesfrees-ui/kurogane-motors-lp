# KUROGANE MOTORS TOKYO — Demo LP

架空のバイク専門店「黒鉄モーターズ」のデモンストレーションLPです。
スクロールに連動して3Dのバイクがパーツから組み上がり、完成後に走り去る演出を実装しています。

**Live Demo:** https://freeeeeeesfrees-ui.github.io/kurogane-motors-lp/

## 技術構成

- **スクロールスクラブ再生** — 組立ムービー(20秒)を10fpsのWebPフレーム連番(200枚)に変換し、GSAP ScrollTriggerでスクロール位置に同期してcanvasに描画(Apple製品ページと同方式)
- **縦横で別ムービー** — 横画面は横長版(`frames/`・約4.8MB)、縦画面はスマホ用縦長版(`frames-m/`・約4.6MB)を読み込み、それぞれの編集に合わせた区間マッピングを適用。画面回転時は自動リロードで切替
- **区間マッピング** — 動画の7チャプターごとにスクロール量を配分し、各チャプターにキャプションを同期表示
- ビルドツール不要。静的ファイルのみ(GSAPのみCDN読み込み)

## ローカルで開く

```bash
python -m http.server 8098
```

http://localhost:8098 を開いてください。
